# 相册分享与视频交付

## 文件分享

生成 HTML 后可直接交付，也可用「下载相册」保存。HTML 内含照片，朋友无需安装 Skill。聊天应用会限制 HTML 预览时，让朋友下载后在完整浏览器里打开；若需要点击即看，用在线发布。

本地相册的「分享相册」提供下载和发布提示。通过非本地 HTTP(S) 地址打开时会提供网页地址与复制按钮，但当前 URL 不保证匿名可访问，仍要核对网站的访问范围。localhost、局域网和 file 地址不显示成公众分享地址。

## 在线发布

用户指定平台或既有网站时沿用该平台；环境有 Sites 等专用发布能力时，加载其技能并按原生流程发布。将生成 HTML 放入静态网站的 `dist/index.html`，保留全部嵌入资源、照片和交互，不必为单个相册引入服务端。

用户要让朋友无需账号直接访问时，使用支持该访问范围的发布方式。若工具只完成私有发布，说明当前范围，不把只有所有者能看的 URL 称为公开链接。已有站点保留用户指定的访问设置。遵守工具的原生授权流程，已授权的操作无需另设重复确认。

部署成功后返回工具确认的真实 URL；如果发布能力不可用或需要用户连接账号，保留可分享 HTML，并说明缺少的具体能力。不要编造网址，也不要擅自用外部文件上传服务代替。

## 视频导出

1. 打开生成的相册，选择要导出的相册，点「导出视频」。视频从第一页开始，包含该相册全部照片。每页停留默认 4 秒；页数多时可按用户要求调整。
2. 点击「开始导出」，保持页面在前台直到完成。页面直接录制本地画布，不需要屏幕、摄像头或麦克风权限；画布按相册布局绘制原图和文字，1080p、30 fps。其翻页用书脊固定的透视模拟，与网页交互动画不是逐像素屏幕录像。
3. 完成后点击下载。浏览器根据实际支持能力生成 MP4 或 WebM；查看下载文件格式，不仅看后缀。不支持编码时用支持的桌面浏览器，不绕过权限或安全提示。
4. 用户要社交平台视频时优先交付 H.264 MP4；必要时转换：

```bash
python3 scripts/convert_video.py <下载的视频路径> -o <新输出路径>.mp4
```

转换依赖 FFmpeg。优先用 PATH 中的现有 FFmpeg；也可用环境中 `imageio_ffmpeg` 提供的可执行文件，或传 `--ffmpeg <路径>`。缺少时按当前环境权限从正常软件源安装到合适环境，不假定别人的电脑有作者本机的路径。

可选音乐（用户提供或授权）：

```bash
python3 scripts/convert_video.py <视频> -o <新输出>.mp4 --music <音频路径> --volume 0.25
```

短音乐循环到视频结束，长音乐截断；输出 H.264、yuv420p、AAC、faststart。原视频保留；已有输出不会被覆盖。默认不添加音乐。竖版社交视频需另按用户要求重排原图，不能直接裁掉横版相册；当前内置导出为横版。

导出与取消均应释放录制资源。取消或页面失焦导致停止时，保持相册可继续浏览，不把未完成片段当成完成视频。对新的导出能力至少验证视频能解码、照片和文字有显示、翻页连续、首末页包含预期内容。完成后交付文件链接，并注明真实格式、尺寸和有无音乐。
