# 文档生成翻页书

## 使用

```bash
python3 scripts/build_document.py <文档绝对路径...> -o <输出绝对路径>.html --title <书架标题>
```

每个文件生成一本书。接受 PDF、DOCX、DOC、TXT、MD。默认输出工作区 `outputs/文档翻页书.html`。使用已有 Python 环境中的 Pillow、pypdfium2、python-docx、reportlab；优先通过工作区依赖工具定位，不依赖浏览器外网加载库。照片与文档走各自脚本；不要把文档扩展名冒充图片。

## 保留和重排

- PDF：逐页渲染，保持原有页面和顺序，完整显示，不裁剪。扫描件同样可翻阅，但不自动 OCR。页面内有文字时附带隐藏的可访问文字。
- Word：DOCX 按正文顺序提取标题、段落、基础列表、表格和内嵌图片，重排为 A5 阅读书页。长段落自然跨页，图片完整显示。不是 Word 原始分页的精确复刻。复杂字体样式、页眉页脚、脚注、文本框、修订和复杂表格需要优先请用户从 Word 导出 PDF；遇到这些内容报告实际提示，不宣称全部保留。
- 旧 DOC：本机有 `textutil` 时先转 DOCX；否则请用户另存 DOCX/PDF。
- TXT/MD：保留段落，Markdown 支持基础标题，非完整 Markdown 排版引擎。

中文重排需可用中文 TrueType 字体，脚本会查找系统字体；缺少时通过 `--font <ttf绝对路径>` 指定用户已有字体，不静默输出缺字。PDF 可用 `--password` 打开用户授权的加密文件，不绕过加密。默认页图长边 2200 像素，可用 `--max-side 800–6000` 调整清晰度和体积。

## 阅读体验与验证

文档使用完整页图、双页阅读，末页为奇数时右侧自然留白。点击书页支持放大查看；文档隐藏照片的交换与尺寸编辑功能，防止改变正文顺序。首页使用阅读书籍措辞，页数来自实际生成结果。HTML 内嵌页面，离线可用；页面图像不能直接选择文字或全文搜索，不把它称为文字阅读器。

检查 PDF 页数、首页、末页和页面顺序；Word 检查长段落跨页、标题、表格、图片与结束内容，报告无法保留的结构。至少预览一跨页、末页和放大，确认前后翻页及关闭正常。不要修改原文件。分享与视频沿用 `share-and-video.md`，未经用户明确要求不发布文档。
