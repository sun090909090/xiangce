# 开书与翻页运动

## 默认序列

生成器已实现以下序列，修改排版时应保留这些连续性约束：

1. 从用户点选封面的实际屏幕位置起步，沿同一封面移动、放大、转正，约 650 ms；不重新造一张不同排版的封面。
2. 中央封面短暂停留约 120 ms。闭合书本以右半页为主体，封面宽高和后续右页完全一致。
3. 封面绕左侧书脊从 0° 转到 −180°，约 850 ms；书本容器同步向右移动半个页宽，使最终双页整体居中。封面背面就是最终左页，右侧内页在盖子掀起后露出。
4. 左页在封面背面落下前不重复显示；闭合容器必须透明，不能提前露出一整块双页白底。工具栏在开书完成后出现。

这些时长是本模板的推荐参数，不是录屏源代码。参考录屏可见约 3.9–4.4 秒取书转正、4.4–4.8 秒停驻、4.8–5.2 秒封面展开；另一次约 11.8–13.1 秒出现相同序列。录屏包含书库筛选、分类切换及进入文章，不是连续翻阅摄影相册。不要称内页翻动是逐帧复刻的原站效果。

## 内页规则

- 桌面前翻：右页正面绕左书脊旋到左边，背面展示目标跨页左页；反翻对称。
- 铰链位置固定在双页中线。不要对整张纸加 `translateZ`：这会使书脊脱离书本，造成漂移。
- 正背面隐藏背面透视；纸页内容始终按原图比例完整显示。
- 默认 900 ms，连续缓入缓出，在接近 90° 时最快，贴回书页时减速。光照随角度升降，不能在中点瞬间切换。
- 当前为平面纸页的透视翻动，不是柔性纸张卷曲模拟。若用户明确要求卷曲，需另做连续曲面或分段网格，先测量参考，不通过晃动整本书伪装纸张弯曲。

## 交互与验证

- 开书和翻页期间阻止重复翻页、自动播放和视频导出。关闭或 Escape 应取消活动动画和临时层；旧动画回调不可写回新相册状态。
- 完成后回到稳定 DOM，删除临时封面、纸页和阴影。关闭后恢复触发按钮焦点。
- 手机默认单页：移入封面后短淡入照片；不硬塞双页透视动画。系统减少动态效果时直接呈现内容。
- 修改动画后预览起点、移入交接、约 90°、落页及最终状态；正常速度检查完整序列。至少验证前翻、反翻、中途 Escape 后重新打开和手机端。只看最终截图不足以验证动画。
- 浏览器视频导出目前从已展开跨页开始，使用 Canvas 翻页。修改互动开书动画不会自动让导出视频包含封面开场；用户要求视频开场时需单独实现并验证，不能误报已同步。
